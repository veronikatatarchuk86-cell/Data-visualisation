# 📊 Data Visualization Demo (Chart.js)

This project is a simple web application demonstrating how to use **Chart.js** to create interactive charts. It displays both a **line chart** and a **doughnut (pie) chart** on a single page.

## 🌐 Features

* 📈 Line chart showing monthly sales data
* 🥧 Doughnut chart representing budget distribution
* 🎨 Clean and responsive UI design
* ⚡ Lightweight and easy to run (no build tools required)

---

## 📁 Project Structure

```
project-folder/
│── index.html     # Main HTML structure
│── stylee.css     # Styling for the page
│── script.js      # Chart configurations and logic
```

## 🧠 How It Works

### 📈 Line Chart

* Displays monthly sales data (in thousands of dollars)
* Uses labels for each month (in Ukrainian)
* Configured with smooth lines and data points

### 🥧 Doughnut Chart

* Represents monthly expenses:

  * Rent (Оренда)
  * Food (Їжа)
  * Transport (Транспорт)
  * Entertainment (Розваги)
  * Clothes (Одежа)
  * Other (Інше)

## ⚠️ Notes

* The Chart.js library is loaded via CDN:

  ```html
  <script src="https://cdn.jsdelivr.net/npm/chart.js"></script>
  ```
* Make sure you have an internet connection for the charts to load.
